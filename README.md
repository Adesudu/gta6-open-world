Palmera Bay is an original top-down open-world crime game: explore a sun-soaked fictional city on foot or by car, steal cars, run 5 story missions, outrun a 5-star wanted system with chasing police, fight on foot, and take taxi fares for cash.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser. No build step, no network requests — the game is plain static files under `game/`.
